# Layered Project Memory for Coding Agents

A markdown memory bank for *state*, a small typed note store (jevmem) for *facts*, and `AGENTS.md` for *rules*: three layers of project memory for coding agents.

Start here:

- **[Article (web)](https://www.daniel-ir.eu/blog/coding-agents-memory)**: the published version of the article.
- **[Article (Markdown)](article/memory-for-coding-agents.md)**: a practical write-up of the approach, from two weeks on a real project.
- **[Paper (PDF)](paper/main.pdf)**: the full paper, with design, evaluation and engineering details.

Related: [jevmem](https://github.com/illescasDaniel/jev-mem).

## Contents

- `article/`: the article, its excerpt, diagrams and images
- `social/`: plain-text summary of the article for social media posts
- `paper/`: LaTeX sources of the paper (`make` builds `main.pdf`)
