# Paper: layered project memory for coding agents

ACM `acmart` (sigconf, nonacm) paper on the memory bank + jevmem. Requirements: TeX Live (full), `latexmk`, `plantuml`, `librsvg` (`rsvg-convert`).

```bash
make figures   # figures/src/*.puml -> svg -> pdf
make           # latexmk -> main.pdf
make clean
```
